# ReadAway Fonts

ReadAway bundles these fonts as static assets so the PWA keeps the
freeCodeCamp Command-line Chic typography offline.

- Lato latin WOFF2 subsets are from Google Fonts and licensed under the SIL
  Open Font License 1.1. See `OFL-Lato.txt`.
- Hack WOFF2 files are from `hack-font@3` and licensed under the Hack Open Font
  License / MIT terms included in `LICENSE-Hack.txt`.

The CSS exposes Hack as `Hack-ZeroSlash` because Hack uses a slashed zero and
matches the intended fCC mono stack for ReadAway chrome.
